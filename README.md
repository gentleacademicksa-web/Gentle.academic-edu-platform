# Gentle Academic Educational Platform

منصة تعليمية تتيح للطلاب التواصل مع المعلم وإرسال الواجبات والاستفسارات عبر واتساب وتليجرام والبريد الإلكتروني.

## المزايا المخطط لها
- صفحة تعريفية للمنصة
- تسجيل الطلاب
- إرسال الواجبات والملفات
- روابط واتساب وتليجرام والبريد الإلكتروني
- لوحة إدارة للمعلم
- تنظيم الدورات والمواد التعليمية
